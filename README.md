## ⭐ **Overview**
The **NDH‑Treaty‑Database** is the centralized, altitude‑neutral repository for all NDH Memoranda of Understanding (MOUs).  
It serves as the **stable nexus** for coordinating agreements across:

- expressive design systems  
- structural hyperstructure layers  
- research substrates  
- Federated Constellation routing  
- meta‑governance altitude  

The repository does **not** activate geometry, hyperstructures, recursion, or governance systems.  
It provides **coordination only**, following the rules defined in the **Founding Charter**.

---

## ⭐ **Purpose**
This repository exists to:

- store and index MOUs safely  
- maintain strict altitude neutrality  
- prevent cross‑layer contamination  
- enforce non‑activation boundaries  
- provide a single source of truth for construction‑phase agreements  
- stabilize Mission Control during NDH ecosystem assembly  

It is the **coordination backbone** for NDH’s multi‑layer architecture.

## ⭐ **Layered MOU System**
MOUs are organized into five altitude‑neutral layers:

- **MOU‑E0 — Expressive Layer**  
- **MOU‑S0 — Structural Layer**  
- **MOU‑SUB0 — Substrate Layer**  
- **MOU‑C0 — Constellation Layer**  
- **MOU‑M0 — Meta‑Governance Layer**  

Each MOU must:

- remain altitude‑bounded  
- include a non‑activation clause  
- include a freeze seal  
- reference the Founding Charter  
- be indexed before being stored
